# Power BI Sales Analytics Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze Amazon clothing sales data and identify trends in sales performance, customer behavior, pricing, product ratings, and delivery patterns.

## 🎯 Project Objective

To transform raw sales data into meaningful business insights through data cleaning, analysis, visualization, and interactive Power BI dashboards.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **Excel / CSV**
- **Data Cleaning & Transformation**
- **Data Visualization**

## 🔄 Data Preparation

Imported data from multiple sources and used Power Query to clean, transform, and prepare the datasets for analysis.

## 📈 Key Analysis Areas

- Sales performance and trends
- Product categories
- Customer purchasing behavior
- Product pricing
- Customer ratings
- Delivery patterns
- Data quality and consistency

## 📊 Dashboard

The Power BI dashboard presents interactive visuals and KPIs that allow users to explore sales patterns and identify important business insights.

## 🔍 Key Insights
