# Power BI Sales Analytics Dashboard
Project Overview
This project presents an interactive Power BI dashboard developed to analyze Amazon clothing sales data and identify trends in sales performance, product categories, customer behavior, pricing, ratings, and delivery patterns.
The objective is to transform raw sales data into meaningful business insights that can support data-driven decision-making.
This repository contains my Power BI practice project focused on data import and cleaning using Power Query. The project demonstrates how to work with multiple data sources, identify data quality issues, and prepare data for analysis.
